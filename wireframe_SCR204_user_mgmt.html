SCR-204
User Management
Quản lý người dùng
Mục đích
Tìm kiếm, xem chi tiết, xử lý vi phạm và quản lý tài khoản người dùng.
Chức năng chính
1
Tìm kiếm / lọc user theo email, nickname, trạng thái, ngày đăng ký.
2
Xem profile — thông tin đầy đủ bao gồm ảnh gốc (không blur).
3
Xử lý vi phạm: cảnh báo / tạm khóa / ban vĩnh viễn.
4
Xem lịch sử match, buổi ăn, report.
eKYC
Admin xem được trạng thái eKYC của từng user. Có thể manual approve/reject nếu API Showcase Gig có vấn đề.
